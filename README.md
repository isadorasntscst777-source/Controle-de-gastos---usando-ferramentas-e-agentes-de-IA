# Controle-de-gastos---usando-ferramentas-e-agentes-de-IA
Projeto desenvolvido com apoio de IA (GitHub Copilot Agent), usada para implementação, estruturação e debugging do código. Requisitos, decisões sobre funcionalidades, direcionamento do projeto, testes e validação dos resultados foram feitos pelo desenvolvedor. Tecnologias: Python, Flask, SQLite, HTML e CSS.
